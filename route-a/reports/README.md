# reports/ — retired

Evidence no longer lives here. All command output is stored with the fixture it
belongs to:

```
fixtures/public/<fixture-id>/evidence/NN-<topic>.txt
```

Rules that still apply, wherever the file ends up:

- Keep the command line on the first line so the result can be replayed.
- Paste the real output, including errors — a failed command is evidence too.
- Never edit output to make it look better; add a note below it instead.

This directory is kept only so old links do not break.
