## 3. 过程中确认的一件事

上传是**按钮显式触发**，不是选文件即传：

```js
// agent.js:1574
if (uploadButton) uploadButton.addEventListener("click", uploadDeliverable);
```

`input` 上没有 `change` 监听。所以第一次用 `dispatchEvent(new Event("change"))`
注入文件时状态栏是空的 —— 那不是 bug，是控件设计。
正确路径是 `DOM.setFileInputFiles` 后再 `click()`，这次拿到了预期文案。

## 4. 局限（明确写出来）

- **`file://` 隐藏分支没有在浏览器里验证**。模板依赖服务端变量，
  要构造 file:// 版本得先把渲染后的 HTML 和静态资源落盘，本次没做。
  该分支目前只有源码断言覆盖（`UPLOAD_AVAILABLE` 判断）。
- **comparison 的「不可用」文案未出现在 innerText**。该卡片默认折叠，
  JS 只在拿到对比数据或失败时展开。Review 12 的判定不依赖这一条，
  M4 已在 187 给出 PASS。

## 5. 对 Review 12 的意义

Review 12 的核心命题是「缺失必须如实表达，不能冒充通过」。
本次在真实页面上看到的是：

```text
scope：unknown
bounded：unknown
```

没有「通过」「已覆盖」「符合」这类词。这条现在有 L1 证据（本机页面实测），
不再是只靠读代码推断。
