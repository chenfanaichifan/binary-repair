## Required SHA256SUMS order

The current lines are grouped by directory, not sorted. Regenerate with:

```bash

  | LC_ALL=C sort \
  | while IFS= read -r f; do sha256sum "$f"; done > SHA256SUMS
```

by directory, so the checker fails; regenerate with the command above and do not
