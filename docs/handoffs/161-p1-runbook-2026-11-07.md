## 1. M1: create the job

```bash
curl -sS -X POST http://127.0.0.1:8000/api/jobs \
  -F defect='CWE-416 use-after-free no-input' \
  -F valid_tests='valid-no-input' \
  -F environment='Ubuntu 22.04 x86-64, runner uid 1003' \
  -F binary=@/path/original.elf
```

Record `JOB_ID` from the response.

Approve and start:

```bash
# contract body is the fixture contract; manifest hash must be the package manifest
curl -sS -X POST http://127.0.0.1:8000/api/jobs/$JOB_ID/approve \
  -H 'Content-Type: application/json' \
  -d '{"contract_revision":1,"reviewer_label":"P1","manifest_sha256":"<64hex>","contract":'"$(cat contract.json)"'}'

curl -sS -X POST http://127.0.0.1:8000/api/jobs/$JOB_ID/runs \
  -H 'Content-Type: application/json' \
  -d '{"contract_revision":1,"manifest_sha256":"<64hex>","idempotency_key":"p1-'"$JOB_ID"'"}'
```

Record `RUN_ID`, `ROUTE_B_ATTEMPT_ID`, and `ROUTE_A_ATTEMPT_ID` from the response.
