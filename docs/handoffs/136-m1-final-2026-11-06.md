## V3 summary normalisation

A behaviour row with no readable V3 manifest used to return
`valid: {passed: None, total: None}` and `invalid: {None, None}` with
`input_mode: None`.

Now, in `_v3_summary`:

- counts normalise to `0/0` when the manifest is absent;
- `input_mode` falls back to `"none"`;
- `invalid_applicable` stays `False` for a zero-invalid run.

This is a presentation fix only. `result` still comes from the stored row, so a
`not_run` gate stays `not_run`; nothing is promoted to a pass.
