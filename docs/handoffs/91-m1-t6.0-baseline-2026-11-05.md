- `app/services/orchestration.py` passes `expected_sha256=None` and persists
  `"expected_sha256": null`, because approval binds the reviewed scope, not a
  candidate hash.

  supplies an approved candidate hash that differs from the candidate.

Evidence:

```text

```

Two tests pin the decision in opposite directions:
`test_candidate_differing_from_original_can_succeed` (a real candidate is not
the original, so it must be allowed) and
`test_candidate_vs_explicit_approved_candidate_mismatch_blocks_success`
(an explicit approved hash still rejects a different candidate).

## 3. Environment note for every later run

Running the suite from a deep temporary root fails spurious tests on Windows
(`LongPathsEnabled = 0`, 266-character `tmp_path`). Point the temp variables at
a short directory first:

```powershell
$env:TMPDIR="D:\brtmp"; $env:TEMP="D:\brtmp"; $env:TMP="D:\brtmp"
```

With that, the full suite on this base is the recorded
273 collected / 269 passed / 3 skipped / 1 failed; the single failure is
`test_static_routeb_bundle` (no `readelf`/`objdump` on this host).
