## 2. T8.1 — assistant endpoints

```
GET  /api/jobs/{id}/assistant   latest stored plan (404 when none)
POST /api/jobs/{id}/assistant   generate + persist, body {"mode": "scripted"|"llm"}
```

Both call `app/services/assistant.py` (`get_plan` / `generate_plan`). The
response wraps the stored plan:

```json
{"id": "...", "job_id": "...", "mode": "scripted", "plan": {...AssistantPlan...},
 "model": null, "usage": null, "created_at": "..."}
```

`plan` is the `AssistantPlan` body (`schema_version`, `job_id`, `mode`,
`summary`, `steps[]`, `questions[]`, `model`, `fallback_reason`).

The safety property is structural, not advisory: `generate_plan` writes exactly
one `assistant_plans` row. It has no path to `contracts`, `runs`, `attempts`,
`obligations`, or `jobs.phase`. `test_assistant_endpoint.py` proves it by
comparing the snapshot before and after, and by asserting `runs = 0` and
`obligations = 0`.

### Defect found in M5's persistence

`get_plan` ordered by `created_at DESC, id DESC`, and `created_at` only has
second precision. Two plans generated in the same second resolved to a random
one, so `GET` could return the older plan. Fixed to `ORDER BY rowid DESC`
(insertion order). `save_plan` now also returns `created_at`.

## 6. T6.6 — provider proposals are staged, never accepted

New `app/services/candidate_staging.py` plus:

```
GET  /api/jobs/{id}/proposals   staged proposals, newest first
POST /api/jobs/{id}/proposals   body {"text", "source", "model"}
```

A staged record is written under `jobs/<job>/staging/proposals/<sha256>.json`
and says:

```json
{"status": "staged", "candidate": false, "verdict": null, "obligations_evaluated": 0}
```

Design points:

- the digest of the text is the identity, so restaging is deduplicated;
- the id is validated as a 64-char hex digest before it touches a path;
- 64 KiB limit; empty/whitespace text rejected;
- no run, attempt, obligation, or verdict is created.

A proposal only becomes a candidate when a route produces candidate bytes. Those
bytes then go through ingest and V0-V5 exactly like any other candidate. The
V4-only gap test from the previous record still proves that six `passed` and one
`not_run` stays `inconclusive`.
