## F1 — A: do not write evidence package back

Choose **A**.

Evidence bundles are byte-bound by SHA256SUMS. A test must not rewrite a
tracked package to fix a newline expectation; that invalidates the audit trail.

Correct pattern:

```text
copy package to tmp_path
normalize the copy if the test needs LF
run against the copy
keep the tracked package bytes unchanged
```

Choose B only when the package itself is intentionally regenerated and its
SHA256SUMS is updated in the same commit; never as a test convenience.

## F2–F4 — platform tests

Rule:

```text
ELF loader/format/execution semantics -> skipif(os.name == "nt")
generic subprocess behavior, no ELF requirement -> sys.executable is allowed
```

Do not use `sys.executable` to mask a Linux-ELF failure in a test that claims to
exercise ELF behavior.

Recommended:

```python
pytestmark = pytest.mark.skipif(os.name == "nt", reason="Linux ELF execution")
```

and report the skip reason in the suite summary. Do not silently downgrade to a
different binary.

## F5 — independent-views count

Do not simply replace `7` with `7 + len(actual)`; that could hide missing views.

Use both:

```python
views = sorted((bundle / "independent-views").glob("*.txt"))
assert len(views) in (0, 5)
expected = 7 + len(views)
assert len(sums_rows) == expected
assert {p.name for p in views} <= {row.name for row in sums_rows}
```

So:

```text
no tools -> 7
all five views -> 12
partial views -> fail, not silently accepted
```
