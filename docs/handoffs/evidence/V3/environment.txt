Stdlib-only, refuses non-Linux / non-root / missing `--guest-ack`. It records
`(return_code, stdout_hex, stderr_hex)` per case and judges nothing; a signal
death is normalised to `128+N` so the SIGSEGV case reads as 139, matching the
fixture provenance.

## Execution

Each case ran as `./original <input>` with the binary copied into a fresh
scratch dir under that exact basename (`/var/tmp/behaviour/{original,candidate}`),
which is the form the manifests declare. The scratch dir is deleted and rebuilt
per run so a stale artefact cannot be mistaken for this run's output.
