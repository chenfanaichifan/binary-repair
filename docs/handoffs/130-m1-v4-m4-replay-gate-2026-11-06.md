## 0. Gate

`V4Evidence.replay.verified_by` is optional in the producer-facing schema and
must equal `"m4"` only in the gate-facing validation:

```
validate_v4_evidence(..., require_independent=True)
  -> replay.verified_by == "m4" required
```

`route_bundle_ingest` and `persist_obligations` call with
`require_independent=True`. A bundle declaring `V4 = passed` without the marker
is downgraded to **not_run**.

## 1. Producer/adapter cannot write the marker

- `from_v4_harness` does not copy or set `replay.verified_by`; even if the
  harness input carries `"verified_by": "m4"`, the adapter drops it.
- `write_v4_evidence` does not add the field; with no value it is omitted by
  `exclude_none=True`.
- Only a separate M4 replay record may set it.
