# Release 2026-11-14 (final coverage closure)

## Status of this document

This is the release procedure and claim boundary for the frozen workbench-v3
tree. The **actual** frozen SHA, gate JSON, provenance bundle and browser
evidence are recorded on the evidence branch `release/2026-11-14-evidence`
(`artifacts/release-gate-2026-11-14/`); the released mainline is tagged at the
same SHA that was gated.

## What is released

- Safe-by-default deterministic repair (whole-image repair only with explicit
  `--allow-whole-image` / API opt-in; target-scoped repairs require
  `patch.target_scope`).
- Frozen release evidence: `--nightly --release-sha` gate (local frozen tree),
  audit/claims sync, 12 mapped non-goals with a quarterly roadmap, provider
  coverage with identity policy and statistics, capability contract, acceptance
  invariants and meta-audit (18 scenarios).

## Evidence layers (do not conflate)

1. Local frozen-tree gate: proves the gated git tree identity and the measured
   checks/artifact digests. Not a GitHub Actions run.
2. GitHub Actions: `ci_status=not_run` for the final SHA; the self-hosted Lima
   nightly job is inert by default (`vars.BINARYREPAIR_RELEASE_GATE`). A CI run
   must be recorded from its own uploaded artifact.
3. Browser: local macOS/Chrome e2e evidence (`artifacts/browser-e2e-2026-11-14/`)
   is not part of the release gate; Linux CI skips are not passes.
4. Binary/runner/guest provenance: recorded digests (audit/acceptance/provider/
   browser artifacts, git tree SHA, Lima version/config digest) are bound in
   `freeze.json`/`gate.json`.

## Known non-goals (not release defects)

12 research/platform non-goals are mapped in
`docs/acceptance/non-goals-2026-11-14.md` and
`docs/acceptance/non-goal-roadmap-2026-11-14.md` with owner, review date,
productization criteria, fallback and quarterly review. Detected non-goal
inputs remain analysis_only/not_run and are never reported as verified.

## Reproduction

```bash
.venv/bin/python scripts/audit_capability_coverage.py --out artifacts/capability-gap-audit-2026-11-14
.venv/bin/python scripts/verify_coverage_gate.py --static-only
.venv/bin/python scripts/verify_coverage_gate.py --local
.venv/bin/python scripts/release_freeze.py --mode nightly --sha "$(git rev-parse HEAD)" --json
```
