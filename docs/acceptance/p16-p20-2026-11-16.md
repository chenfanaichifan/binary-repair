# P16-P20: independent verification, failures, stability and limits (2026-11-16)

## P16: independent verifier integration

Added `scripts/verify_repair_benchmark.py` and an explicit `allow_resize`
path in the byte-level independent verifier for candidates that append a new
PT_LOAD segment while changing only a bounded original prefix.

Applied to 10 candidate records:

- 6 independently **verified**;
- 1 rejected (CWE-121 security semantics);
- 3 not_run because the selected run dirs had no candidate artifact
  (CWE-122/CWE-787/CWE-134).

The verifier uses raw original/candidate bytes, action replay, container/ABI
checks and a real external PoC oracle.  Generator gate values are recorded but
never used in the decision.  This is not yet a complete 8/8 pass.

Evidence: `artifacts/independent-verification-2026-11-16/`.

## P17: CWE-121 / CWE-134

CWE-121 remains `SECURITY_FAILED`: the model-generated block does not produce
the PoC manifest's required candidate exit 1 and exact stderr.

CWE-134 remains `PLAN_INVALID`: the model still does not satisfy the v2
consistency rules after feedback.

These are retained as negative results.  No gate was weakened to force them
green.

## Boundaries

All claims remain scoped: CI/tests do not prove universal repair; a successful
candidate is verified only against its declared PoC/regression surface.
