# P16-R3: PT_LOAD-backed cave ABI and artifact states (2026-11-16)

## Implemented

- `app/services/elf_mapping.py`: PT_LOAD-backed VA/file-offset mapping with
  explicit `MAPPED_FILE_BACKED`, `MAPPED_MEMORY_ONLY`, `OUTSIDE_PT_LOAD`,
  `AMBIGUOUS_SEGMENT`, `INVALID_FILE_RANGE` and `INVALID_ALIGNMENT` states.
- `verification_semantics.derive_abi_blocks` maps declared cave ABI blocks
  through PT_LOAD before section fallback.
- Benchmark verifier reports `ARTIFACT_MISSING` separately from rejected
  candidates and records a per-case `status`.

## Result

10 benchmark case records:

- **7 independent verified** (hard-multicall, hard-sprintf, hard-nonconst,
  CWE-122, CWE-125, CWE-190, CWE-476);
- **1 rejected** (CWE-121);
- **2 ARTIFACT_MISSING** (CWE-787, CWE-134 candidates not present in the
  selected run directories).

The CWE-122 candidate now passes layout-plan, action-replay, target-scope,
ABI, runtime-oracle and independence together. This is a real strict result,
not the earlier allow-resize-only path.
