## P2 errno probes

- `errno_probe=strace`: syscall errno set/unset proxy (existing).
- `errno_probe=ld_preload`: compiles `runtime/errno_dumper.c`, loads it only for
  native dynamic ELF, captures **process-exit TLS errno** via
  `__errno_location`, compares exact regression values.
- CWE121 CI test asserts `errno_probe=ld_preload`, `errno_signature=matched` and
  non-null values; local non-x86 hosts skip explicitly.
- Boundary: this is process-exit errno, not arbitrary function-return errno;
  static/qemu/Lima run reports `not_run`, never fabricated.
