## 2. Hard rules that do not bend

1. **No binary execution, compilation, or symbolic analysis on the host, ever.**
   Everything runs in the disposable guest.
2. **Publish first, notify second.** Nobody waits for a reply before producing
   an artifact.
3. **Missing is not passing.** A missing file, row, or case is
   `not_run` / `NOT VERIFIED`, never `passed`. A `passed` without a command and
   an evidence id is a defect.
4. **`synthetic: true` never substitutes for real data** in a Gate 4 record.
5. **A CI `6/6` is not a formal run.** Only the in-guest run counts.
6. **Do not sign for anyone.** M4's row is waived, not signed; the Lead's
   approval row stays blank until the Lead acts.
7. **One DRI per gate still applies to the decision**, even though one agent
   now produces both sides: Gate 4's record is yours to *write*, the Lead's to
   *approve*.
8. **Logs do not go into chat.** Technical content goes through the repository.
9. **Language:** conversation in Simplified Chinese; every tracked file in the
   repository in English; `worklogs/` is private and gitignored.
10. **No secrets in the repo.** SSH keys and tokens are delivered offline; the
    access record stores fingerprints only.
11. **Verification mode is data, not a footnote.** Every gate record carries the
    waiver line and says "self-verified (single agent)"; a reader must be able to
    tell this result apart from an independently verified one without asking.
