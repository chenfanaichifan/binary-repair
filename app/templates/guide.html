使用说明

这是一份覆盖全部模块的操作手册：代码修复、二进制修复、任务与工作区、服务端历史、 设置、连接器、方法与验证、快捷键、故障排查和安全边界。

1 · 快速开始

打开控制台后，你有两条入口，最终都进入同一个「新建修复内容」会话：

  1. 粘贴代码：把带漏洞的源码贴进输入框，回车。系统给出静态修复建议卡，不执行代码。
  2. 二进制修复：描述缺陷、上传样本、填写用例与契约，逐步确认后创建任务。

助手只做引导与解释；创建任务、开始执行由你点击确认；结论由验收引擎给出。

2 · 代码修复

支持 ``` 围栏代码，也支持不带围栏的多行代码（自动识别代码特征）。结果卡包含：

  • 问题列表：标题、风险级别、CWE、行号、证据与修复建议；首条默认展开解释、影响与「警醒」。
  • 修复后代码：可复制；长代码块可展开/收起。
  • 差异：增/删/上下文着色；可复制差异。
  • 参考：CWE / OWASP 等官方链接。
  • 规则 / 模型：无 provider key 时只走本地规则；配置后模型失败会自动回退规则并标注。

静态建议不是验收结论；复杂漏洞仍需二进制/动态验证。粘贴的代码不会被执行。

3 · 二进制修复

  1. 在对话里描述缺陷；后端返回引导计划。
  2. 按步骤提供样本、缺陷、有效/无效用例、环境与契约；每一步可返回修改。
  3. 复核后点击「创建任务」；任务页每 2 秒刷新状态。
  4. 结果与证据页逐条展示 V0–V5 义务；未回传显示等待占位，不显示 not_run。
  5. 导出 JSON/HTML 报告；导出不代表生产批准。

4 · 任务与工作区

侧栏「任务」只列本浏览器打开/创建过的任务，状态逐条向 controller 核对。支持：

  • 搜索：按名称或任务号过滤。
  • 置顶 / 重命名 / 删除：悬停任务项出现操作；删除只移除本机列表，不删除后端任务。
  • 工作区：顶部工作区按钮可在服务端配置的工作区之间切换；新建会话会带上当前选择。
  • 后端不可查：服务重启或 demo 内存清空后，旧任务会标记「后端已不可查」，仍可从记录进入尝试。

5 · 服务端历史

任务与草稿对话会写入本机服务端 SQLite；同一服务实例内换浏览器可恢复。徽章表示 服务端历史 / 同步中 / 本地暂存 / 草稿已同步。

  • 「新建修复内容」带 ?new=1，清空草稿后开始空白会话。
  • 旧标签页的过期写入会被 generation 守卫拒绝，不会复活已清空的草稿。
  • 默认只监听回环地址；跨设备访问需要你显式改变部署方式并保护会话令牌。

6 · 设置

侧栏「设置」可调整：主题（浅色/深色/跟随系统）、密度、字号、动画、代码字号、 发送键、自动滚动、历史同步、默认工作区/模式、任务排序，以及导出/重置本机设置。 设置保存在浏览器，不会上传；历史同步关闭后只保留本机缓存。

7 · 连接器与插件

连接器是运行时接入点（模型、Ghidra/Rizin/angr/Frida/QEMU、Git、Webhook 等）； 插件是只读 JSON 清单，两者在页面上分区展示。

  1. 在连接器页复制环境变量名或按「接入步骤」安装工具。
  2. 重启 GUI，刷新页面；状态显示「已就绪」只代表具备条件。
  3. 插件模板保存到 plugins/；清单不会被加载执行。

8 · 方法与验证

推荐证据链：复现定位 → 静态恢复 → 符号探索 → 动态确认 → 差分验证 → 回归/模糊。 每一层回答不同问题；「工具跑通」「模型说可以」都不是「补丁正确」。详见 方法与工具 页面。

9 · 快捷键

  • Enter发送（默认；可在设置改为 Ctrl/Cmd+Enter）
  • Shift+ Enter 换行
  • Ctrl/Cmd+ \ 收起/展开侧栏
  • Esc退出专注对话 / 关闭弹层
  • /在输入框开头调用 /skip /status /restart
  • Ctrl/Cmd+ K 打开命令面板，跳转页面、切主题、收起侧栏

10 · 排查与边界

  • 计划服务未接通：检查右侧模型 key/后端；页面会直说未接通，不会用占位内容冒充。
  • 任务 404：重启 mock 服务会清空内存任务；本地列表仍保留记录。
  • 工具未检测到：安装到 PATH、配置环境变量或安装 Python 模块后重启 GUI。
  • 文字看不清：切换主题/密度；若仍存在，请反馈具体页面与主题。
  • 边界：本机工具不执行上传/修复后的二进制；插件只读；导出不代表生产批准。
