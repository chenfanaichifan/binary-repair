关于这个工作台

BinaryRepair 是一个"AI 驱动 + 确定性验证"的二进制漏洞修复工作台，演示双路线修复与证据链。

  • 输入身份：样本 SHA-256 + 安全契约（revision / 哈希 / 复核批准）
  • 两条路线：直接指令修复（反汇编）与恢复 C 回填，必须各自成功
  • 验证阶梯：V0–V5 义务，未执行显示 not_run，不能用"更小的补丁"代替验证
  • 数据来源：mock / http / local 三种模式，接口与契约对齐 controller
