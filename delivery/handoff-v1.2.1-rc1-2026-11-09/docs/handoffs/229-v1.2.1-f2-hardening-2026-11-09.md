## N-10 (accepted limitation)

A custom `BINARYREPAIR_ASSISTANT_KEY_FILE` is protected only when the adapter
process sees the same env. The default filename `assistant.key` is always
rejected regardless of env. Multi-process custom-env deployments must set the
same env or use the default path.
